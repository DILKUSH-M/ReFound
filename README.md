# ReFound – Campus Lost & Found Platform

**ReFound** is a web-based campus Lost & Found platform designed to make reporting, discovering, and recovering lost belongings easier within a college community.

Instead of relying on notice boards, WhatsApp groups, or word of mouth, ReFound provides a centralized platform where students can report found items, search for lost belongings, and submit claims through a verification system.

## Key Features

### 1. Item Reporting
- Report found items with titles, descriptions, categories, and locations.
- Upload images of found belongings.
- Provide contact information for communication.
- Set private verification questions to establish ownership.

### 2. Item Discovery
- Browse reported items through a centralized listing.
- View item descriptions, categories, images, and locations.
- Discover potentially matching belongings.

### 3. Intelligent Claim Verification
- Claimants answer private questions provided by the original finder.
- Uses semantic similarity to evaluate answers rather than relying exclusively on exact text matching.
- Powered by the `all-MiniLM-L6-v2` sentence-transformer model.
- Runs locally using Hugging Face Transformers.

### 4. Manual Claim Review
- Claims requiring additional verification are sent to the original finder.
- Finders can review submitted answers through the Pending Claims dashboard.
- Finders can approve or reject claims.
- Approved items are marked as claimed and removed from the public listings.
- Rejected items become available for claiming again.

### 5. My Claims Dashboard
- Claimants can view their approved claims.
- Finder contact details are made available after approval.
- Provides a direct email link for communication.

### 6. Authentication and Privacy
- User authentication for protected operations.
- Private verification answers are not exposed through public item listings.
- Finder contact information is restricted to authorized claim workflows.

## Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- MongoDB
- Git

### 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd FindIT
```

### 2. Configure the Backend

```bash
cd backend
npm install
```

Create a `.env` file inside the backend directory and configure your environment variables:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

Use the actual variable names expected by your backend configuration.

### 3. Start the Backend

```bash
npm run dev
```

The backend should run at:

`http://localhost:5000`

### 4. Configure the Frontend

Open another terminal:

```bash
cd frontend
npm install
```

### 5. Start the Frontend

```bash
npm run dev
```

The frontend will typically be available at:

`http://localhost:5173`

## How Claim Verification Works

ReFound uses a multi-stage claim verification workflow.

1. **Reporting:** A finder reports an item and provides private ownership verification questions.
2. **Claim Submission:** A claimant selects the item and submits answers to the verification questions.
3. **Semantic Matching:** The backend evaluates the submitted answers using sentence embeddings generated by `all-MiniLM-L6-v2`.
4. **Manual Review:** Claims requiring additional verification are forwarded to the original finder.
5. **Approval or Rejection:** The finder reviews the answers and makes the final decision.
6. **Claim Completion:** Approved items are marked as claimed, and the claimant receives access to the finder's contact information. Rejected items become available again.
